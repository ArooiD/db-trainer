## Что нужно знать

- Компонент — единица развёртывания и независимой эволюции; у него есть собственный API и внутренний мир.
- Границы контекста (bounded contexts) определяются языком предметной области, а не папками в репозитории.
- Через границу компонента общаются только через явный API; инварианты компонента защищает именно эта явная граница.

## Практика

Для интернет-магазина нарисуйте границы контекстов «Заказ», «Склад», «Доставка» и опишите, какие сущности в них пересекаются.
