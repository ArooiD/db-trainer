## Что нужно знать

- SELECT определяет набор возвращаемых столбцов и вычисляемых выражений, FROM — откуда брать строки.
- WHERE фильтрует строки до сортировки и ограничения результата; порядок логических операторов AND/OR влияет на смысл условия.
- ORDER BY делает порядок результата явным, а LIMIT/OFFSET ограничивают объём выборки и используются для пагинации.
