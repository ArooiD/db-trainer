## Что нужно знать

- Оконная функция вычисляет значение для каждой строки на основе набора связанных строк («окна»), не сворачивая их в одну.
- PARTITION BY разбивает вход на независимые окна, ORDER BY задаёт порядок внутри окна, а рамка (ROWS/RANGE) ограничивает часть окна.
- ROW_NUMBER и RANK нумеруют строки, LAG/LEAD дают доступ к соседним строкам, а SUM/AVG OVER позволяют считать скользящие итоги.

## Практика

Пронумеруйте сотрудников в каждом отделе по убыванию зарплаты и выведите топ-3 по каждому отделу с помощью WHERE rn <= 3.
