## Что нужно знать

- Алгоритм — конечная последовательность однозначных шагов, преобразующая входные данные в результат.
- Списки удобны для последовательностей, словари — для доступа по ключу, множества — для проверки уникальности и операций над наборами.
- Оценка O(n), O(log n) или O(n²) показывает, как растёт объём работы при увеличении входных данных; линейный поиск против бинарного — классический пример.
