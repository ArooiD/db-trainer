## Что нужно знать

- Условия (if/else, switch) выбирают ветку выполнения; условия должны быть проверяемыми и не пересекаться по смыслу.
- Цикл повторяет тело, пока выполняется условие; инвариант — утверждение, истинное до и после каждой итерации, помогает доказать корректность.
- break досрочно выходит из цикла, continue пропускает итерацию; злоупотребление ими обычно заменяется более понятным условием цикла.
