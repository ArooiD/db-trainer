## Что нужно знать

- Модули разделяют программу на области ответственности и позволяют повторно использовать код через import.
- Исключения описывают нештатный путь выполнения; их следует обрабатывать там, где программа может принять осмысленное решение.
- Чтение и запись файлов — источник ошибок и медленных операций; их выносят на границу программы и оборачивают в контекстные менеджеры.

## Практика

Разделите обработку CSV на функции чтения, проверки данных, расчёта статистики и формирования отчёта; оформите работу с файлом через with open(...).
