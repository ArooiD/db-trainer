## Что нужно знать

- JavaScript в браузере выполняет код в событийной модели и реагирует на действия пользователя, таймеры и завершение операций.
- Promise представляет будущий результат, а async/await позволяет описывать асинхронную последовательность линейно.
- DOM — объектное представление документа; изменение DOM следует отделять от вычислительной логики приложения.

## Практика

Создайте интерфейс, который асинхронно загружает набор данных, показывает состояние загрузки и выводит обработанный результат.
