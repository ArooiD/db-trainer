## Что нужно знать

- Git хранит снимки проекта в виде связанных коммитов; ветка — это лёгкий указатель на коммит.
- Merge сохраняет историю веток, rebase переписывает их линейно; выбор зависит от того, важна ли вам исходная структура ветвления.
- Понятные сообщения коммитов и небольшие атомарные изменения упрощают ревью и разбор регрессий через bisect.

## Практика

Создайте feature-ветку, сделайте два коммита, смержите её обратно и изучите граф истории через git log --graph.
