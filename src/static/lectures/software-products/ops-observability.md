## Что нужно знать

- Наблюдаемость — возможность по внешним сигналам понять внутреннее состояние системы без остановки сервиса.
- Три столпа — структурированные логи, метрики с временными рядами и распределённая трассировка запросов.
- SLO формулируют приемлемый уровень обслуживания, а алерты строят на симптомах для пользователя, а не на внутренних аномалиях.

## Практика

Для локального сервиса настройте health-check эндпоинт, соберите базовые метрики (latency, error rate) и опишите SLO на 99% успешных запросов.
